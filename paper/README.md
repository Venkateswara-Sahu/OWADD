# Vigil manuscript

LaTeX source of the Vigil paper (calibrated attribution for security drift), plus the
figure and table scripts that render it from experiment artifacts. The manuscript is in
preparation; nothing here is accepted or published, and every number in it is traceable to
an artifact listed below.

## Build

`main.tex` compiles cleanly under both `pdflatex` (arXiv TeX Live) and `tectonic` / XeLaTeX
(loading Times via `mathptmx` with `T1` font encoding):

```bash
tectonic --keep-logs --keep-intermediates main.tex  # writes main.pdf + main.bbl (needed by arXiv)
# or: pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```

The build must finish with zero overfull boxes and zero undefined references; check with
`grep -c Overfull main.log` and `grep -cE "Reference .* undefined" main.log`.

## Layout

- `main.tex` — preamble, title/abstract, section includes, bibliography.
- `sections/` — modular sections and generated tables:
  - `calibrated_method.tex` — permutation null, $\alpha/2$ union split, and greedy edge peeling.
  - `calibration_experiment.tex` — null calibration, localisation, power, cost, and block-exchangeability experiments.
  - `calibrated.tex` — fully generated by `scripts/render_calibrated_tables.py` from `artifacts/runs/calibrated-study-v3/summary.json`.
  - `blocks_null.tex` — fully generated by `scripts/render_blocknull_table.py` from `artifacts/runs/calibrated-blocknull-v2/summary.json`.
- `figures/` — `generate_figures.py` writes the vector PDFs and PNGs used by `\includegraphics`.

## Scope note

Claims in this manuscript are limited to what the artifacts above show: the calibration
study covers synthetic pools plus the prepared CICIDS2017 and normal-only NSL-KDD matrices,
not raw packet captures, and exact family-wise level control under the permutation null holds
only for exchangeable rows within a window (see `tab:block-null`).
