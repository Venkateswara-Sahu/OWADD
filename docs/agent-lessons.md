# Agent lessons — dead ends and what to do instead

One row per abandoned approach. Read the relevant rows (grep the area) **before** starting
work in that area, so the same mistake is not paid for twice.

Rule of thumb: an entry is written the moment an approach is abandoned, not at the end of
the session. If a hypothesis took more than 15 minutes and failed, it belongs here.

| Date | Tried | Why it failed | Do instead |
|---|---|---|---|
| 2026-10-24 | Ranked LLM providers by list price (`sort: "price"`) using a 22-token test prompt | Ranking inverts with payload size: at 22 tokens the $0.08/M sticker wins, at 20k tokens cache-hit pricing dominates and the $0.15/M host is 11× cheaper | Benchmark with a realistic payload (pi sends ~20k prompt tokens, 35 tools, `reasoning.effort=high`) before concluding anything about cost |
| 2026-10-24 | Assumed `samplingParams.provider` in `~/.pi/agent/models.json` was being ignored, because routing stayed on Makora | Config was applied correctly; Makora was genuinely cheapest at a 99% cache-hit rate | Prove config delivery with a sentinel value first (`only: ["zzz-nonexistent/fp8"]` → expect `failed_routing_step: "Filter by Allowed Providers"`) before blaming the config layer |
| 2026-10-24 | Trusted a provider list without checking quantization coverage | `deepseek-v4.1-flash-1017` has 34 endpoints split fp8=15, unknown=14, fp4=4, mxfp4=1; pure price routing lands on 4-bit hosts | Always pin `quantizations` when output quality matters, and check the endpoint table for what the filter actually admits |
| 2026-10-24 | Re-ran `pi -p` probes back-to-back to attribute spend deltas | OpenRouter spend accounting lags and charges land on the following run, so consecutive deltas are unattributable | Use `GET /api/v1/generation?id=` for per-request cost, or one probe per minute with explicit credit reads |
| 2026-10-24 | Took "the prepared CICIDS2017 files are not on this machine" at face value and planned a synthetic-only fallback for the real-data cell | `artifacts/prepared/cicids2017-prepared-v1` exists here (2.6 GB: `monday/friday/tuesday*.npy`, `manifest.json`, `identities.sqlite`) and `experiments/calibrated_study.py` loaded it to produce the real-flow null cell | Run `ls artifacts/prepared/` before declaring real data unavailable; a missing-data claim needs a `test -d` behind it |
| 2026-10-24 | Generated LaTeX tables by re-escaping table text with `chr(92)` / crafted `\u` escapes in a heredoc | The escaping collapsed into control characters (`\x0b`, `\x08`) and the generator wrote a `\end{tabular}` outside its `\begin`, so `\\begin` never landed in the file | Write LaTeX literals in a real file (`write` tool) or plain `\\` escapes; then `grep -c '\\\\begin'` the output as a post-write check |
| 2026-10-24 | Explained the asymptotic relational pathway's false alarms as a tie-driven effective-sample-size problem (long runs of identical values shrink the effective `n` for the Fisher-`z` variance) | Refuted by `experiments/calibrated_diagnostics.py`: on CICIDS2017 Tuesday flows the per-edge analytic rejections are 0.6% for edges with <25% unique values but 4.3% for edges with >75% unique values, and the tie-free multivariate-$t_3$ population still rejects in 50.0% of draws (vs 5.0% permutation). Binning by unique fraction is a negative control, not the mechanism | Attribute the failure to the Gaussian **joint** assumption (tail dependence / dependence across edges), which the rank transform does not repair; keep the unique-fraction bins in the artifact as the control that rules ties out |
| 2026-10-24 | Edited repo files while a long provenance-hashed study was mid-run | `experiments/provenance.py:88-123` hashes every git-tracked/untracked file (`git ls-files --cached --others --exclude-standard`) into `source_tree_hash`, so one doc edit changed the cache key and a 568-case run restarted from zero | Freeze the tree for the duration of a study run, or run it from a pristine copy; writes under `artifacts/` are safe because it is gitignored |
| 2026-10-24 | Built a regex containing `\\\\cite` inside a bash heredoc (`<<'PY'`) | git-bash still collapsed the backslashes, Python saw `\cite` and raised `re.error: bad escape \c`, so the citation audit silently never ran | Put scripts with backslash-containing regexes in a file via the `write` tool and run the file |
| 2026-10-24 | Passed `/tmp/x.md` to a Python CLI after writing via bash `cat > /tmp/x.md` | bash's `/tmp` is a virtual mount (`C:/Users/.../Temp`), Python's `/tmp` is `C:\tmp`, so outputs landed in two different directories and `pathlib.Path` could not find them | Use `C:/tmp/...` explicitly on both sides, or keep artifacts inside the repo |
| 2026-10-25 | Treated the artifact/schema fingerprints as dataset identity | A `calibrated-study-v3` rerun over the same `--prepared` directory produced different bytes for the real pools while file count, size and dtype were identical, so two different inputs shared one cache key and the resume path could mix them | Hash content: `experiments/calibrated_data.py::_content_digest` records a sha256 per split and the study rejects a cached result whose digest differs |
| 2026-10-25 | Considered rank-transform + residual kernel ridge as a fix for the resampling contradiction | `experiments/calibrated_identifiability.py` shows resampling tuples restores either residual dependence (block resampling) or marginals (i.i.d. bootstrap) and never both, and any residual-fitted model extrapolates into regimes absent from the reference | Rank-normalize before a parametric model, or report the impossibility instead of shipping a fit that cannot be calibrated |
| 2026-10-25 | Ran two full 10-minute test suites in parallel to save wall time | Both aborted mid-run (`[bg] aborted` markers) with four spurious failures inside `tests/experiments/test_calibrated_study.py`; the identical tree passes `252 passed, 13 warnings in 604.04s` when the suites are run one at a time | Serialise full-suite runs, use `-p no:randomly`, and only believe a failure whose test id you captured |
| 2026-10-25 | Started chunked `bg_run` jobs for the localisation stage without `cd` into the repo | `python -m experiments.calibrated_study` died immediately with `ModuleNotFoundError: No module named 'experiments'` because the background shell's cwd was not the project root | Prefix every `bg_run` command with `cd "<repo>" && ...` |
| 2026-10-25 | Watched a study with `tail -f <bg log> | grep --line-buffered "[null]"` | git-bash `tail -f` over the Windows temp path never flushed through the pipe, so a healthy 44-minute job looked frozen | Poll `bg_status` (elapsed + log tail) or grep the log after the job exits |
| 2026-10-25 | Attributed a one-off full-suite failure to editing the tree during the run | `grep -rn "fingerprint" tests/ --include=*.py` returns no matches, so no test hashes the work tree; the attribution was unsupported and the same suite passes on an unchanged tree | When a suite fails once and passes on rerun, capture the test id before retrying, and do not name a mechanism without a grep or a log line |
