01 / The system

From changing data
to inspectable signals.

A Python package for monitoring numeric feature streams. The components expose signals for investigation—not automated security verdicts.

  1. 01 / PREPARE

    Establish a reference

    Fit preprocessing on training data. Keep feature order consistent across numeric batches.

  2. 02 / RECONSTRUCT

    Compare representations

    Adaptive and frozen autoencoders provide reconstruction-error signals.

  3. 03 / MONITOR

    Look for change

    Replicated statistical tests and KDE novelty scores flag batches for investigation.

  4. 04 / INSPECT

    Rank feature errors

    Inspect changes in per-feature reconstruction error alongside the drift alert.

Conclusion / Mixed evidence

Useful in some settings.
No general superiority established.

Training improved localization in some dependency-shift conditions, but also hurt small-mean localization. Simple KS and correlation baselines remained stronger in several tested conditions.

The continuation criterion was not met. The original default is retained; alternative rankings remain experimental.

Study boundaries & publication status
  • Semi-synthetic development experiments, not held-out attack detection or live deployment validation.
  • Feature rankings are diagnostic, not causal explanations. Uncertainty intervals are exploratory.
  • The historical manuscript is unpublished and superseded. No Vigil publication or proven method novelty is claimed.
  • Protocols and compact reports are public; raw datasets, caches and per-run outputs are not distributed.

PYTHON / BASIC USAGEvigil-drift
# pip install vigil-drift
from vigil import Vigil

# Provide your preprocessed data and column names.
monitor = Vigil(feature_names=feature_names)
monitor.fit(baseline_data)

for batch in stream:
    result = monitor.detect(batch)

    if result.attribution is not None:
        for feature in result.attribution.top_features:
            print(feature["feature_name"],
                  feature["contribution"])

Contributions are normalized reconstruction-error scores—not probabilities or percentages of input change.
