Capabilities

Drift detection that
actually explains itself.

Most drift detectors tell you that something changed. OWADD Sentinel tells you what changed and by how much.

🔍
Unsupervised Detection
Replicated T-Test on autoencoder reconstruction errors. No ground-truth labels required — works in real production streams.
🆕
Novel Class Recognition
A frozen mirror autoencoder (A_KC) isolates unknown attack classes from distribution drift. Knows the difference between "changed" and "new".
📊
Feature Attribution
Novel contribution — DriftAttributor ranks which input features caused the drift. Turns alerts into actionable intelligence for security analysts.

Production Ready
FastAPI REST service, Kafka stream integration, Airflow retraining DAGs, MLflow experiment tracking, and Docker for one-command deployment.

Quick Start

Three lines to
start detecting drift.

Install the package, fit on baseline data, then call detect on each incoming batch.

python 
# pip install -e ".[dev]"  (after cloning)

from owadd_sentinel import OWADDSentinel

sentinel = OWADDSentinel(feature_names=your_feature_names)

# Phase 1: offline training on baseline traffic
sentinel.fit(baseline_data)

# Phase 2: detect on every incoming batch
for batch in stream:
    result = sentinel.detect(batch)

    if result.drift_detected:
        print(f"⚠ Drift severity={result.drift_severity:.2f}")

        for feat in result.attribution.top_features:
            print(f"  {feat['feature_name']}: {feat['contribution']:.1%}")

# ⚠ Drift severity=1.00
#   service_eco_i:              15.3%
#   dst_host_same_src_port_rate: 12.3%
#   srv_diff_host_rate:          11.1%
